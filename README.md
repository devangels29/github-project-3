✈️ Calculadora de Suministros para un Viaje
📌 Descripción

Este proyecto consiste en un programa desarrollado en Python que permite calcular la viabilidad de los suministros disponibles durante un viaje.

El usuario introduce diferentes datos relacionados con el viaje y los suministros, y el programa utiliza operaciones matemáticas para determinar si los recursos disponibles son suficientes para cubrir las necesidades del viaje.

El proyecto está diseñado como una práctica de los conceptos fundamentales de Python y de la interacción con el usuario mediante consola.

🎯 Objetivo

Integrar la interacción con el usuario y las matemáticas para resolver un problema práctico relacionado con la planificación de suministros durante un viaje.

🧠 Conceptos utilizados

Durante el desarrollo del proyecto se practican los siguientes conceptos:

input() para recibir información del usuario.
Conversión de datos utilizando int() y float().
Operaciones matemáticas.
Variables y almacenamiento de datos.
Cálculos relacionados con cantidades y consumo.
Formateo de resultados mediante f-strings.
Salida de información utilizando print().
⚙️ Funcionamiento

El programa solicita al usuario los datos necesarios para realizar los cálculos.

A partir de estos datos, se realizan operaciones matemáticas para determinar:

La cantidad de suministros disponibles.
El consumo estimado durante el viaje.
La cantidad de suministros necesaria.
Si los recursos disponibles son suficientes para completar el viaje.

Finalmente, el programa muestra los resultados de manera clara y organizada.

💻 Ejemplo de ejecución
====================================
   CALCULADORA DE SUMINISTROS
====================================

¿Cuántos días durará el viaje?: 5
¿Cuántas personas viajarán?: 2
¿Cuántas unidades de comida hay?: 25

Consumo diario: 4 unidades
Consumo total: 20 unidades
Suministros disponibles: 25 unidades

✅ Los suministros son suficientes.
Suministros restantes: 5 unidades
🚀 Requisitos

Para ejecutar el proyecto necesitas:

Python 3.x
Una terminal o editor de código compatible con Python.
